# Generator Template Foto

## Menjalankan

1. Ekstrak folder proyek.
2. Buka `index.html` melalui browser modern.
3. Pastikan koneksi internet tersedia saat pertama kali membuka halaman agar Tailwind CSS CDN, Google Fonts, dan pustaka HEIC dapat dimuat.

## Struktur

- `index.html` — struktur halaman dan pemanggilan Tailwind CSS.
- `style.css` — aturan tambahan untuk komponen khusus dan detail visual.
- `app.js` — logika canvas, unggah gambar, penyimpanan lokal, riwayat, dan ekspor.

Ukuran hasil tetap 1080 × 1350 piksel. Data tersimpan di browser/perangkat yang sama.
